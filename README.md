# Moneva

Moneva adalah website keuangan pribadi yang membantu Anda memahami, mengatur, dan mengembangkan kondisi keuangan dengan lebih baik. Website ini berisi simulator anggaran, pusat pembelajaran literasi keuangan, dan dashboard untuk mencatat pemasukan serta pengeluaran.

Website ini dibuat untuk mengikuti perlombaan Web Design di INVOFEST 2026

## Fitur

- **Simulator Keuangan**: hitung pembagian pemasukan, kebutuhan, keinginan, dan tabungan. Metode anggaran 50/30/20 sudah tersedia.
- **Pusat Pembelajaran**: materi edukasi keuangan dalam bentuk video dan artikel yang mengacu pada sumber resmi, termasuk OJK.
- **Dashboard Keuangan**: catat pemasukan dan pengeluaran, lalu lihat ringkasan arus kas.
- **Mode terang dan gelap**: tampilan dapat disesuaikan di pengaturan.

## Teknologi

- [Vite](https://vitejs.dev/)
- [React](https://react.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) untuk ikon
- Font: Plus Jakarta Sans

## Persyaratan

- Node.js 18 atau lebih baru
- npm, pnpm, atau yarn

## Instalasi

1. Clone repositori:

   ```bash
   git clone https://github.com/USERNAME/moneva.git](https://github.com/haelsryan/Website-Lomba.git)
   cd Website-Lomba
   ```

2. Pasang dependensi:

   ```bash
   npm install
   ```

3. Jalankan server pengembangan:

   ```bash
   npm run dev
   ```

4. Buka `http://localhost:5173` di browser.
